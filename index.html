01 / Introduccion

Análisis de rendimiento en aplicaciones 3D web

Laboratorio práctico que integra conceptos teóricos de arquitectura computacional con experimentación real sobre una aplicación interactiva 3D desarrollada con React y Three.js.

🎯

Objetivo del Proyecto

Analizar el impacto de arquitecturas RISC vs CISC, tipos de memoria, computación paralela y herramientas de monitoreo sobre el rendimiento de una app 3D interactiva.

RISC CISC 3D
📊

Variables de Estudio

FPS, Heap Memory, RAM JS, uso de CPU, estabilidad del sistema y eficiencia energética bajo diferentes escenarios de carga.

08 / Conclusiones

Hallazgos del Laboratorio

Conclusiones fundamentales derivadas del análisis experimental.

🚀 CISC vs RISC

Los equipos CISC ofrecieron mejor rendimiento bruto en escenarios de alta carga gráfica (1000 bloques), manteniendo mayor estabilidad de FPS y recuperación rápida post-Garbage Collection.

🔋 Eficiencia Energética RISC

Los dispositivos móviles RISC demostraron menor consumo energético y mejor eficiencia térmica. El iPhone 12 Mini destacó por optimización del chip A14 Bionic.

⚙️ Web Workers

La implementación de Web Workers mejoró la estabilidad del sistema: +75% en FPS (20→35) y reducción del 20% en uso de CPU (90%→70%).

📊 Grafana + Prometheus

El stack de observabilidad permitió monitorear en tiempo real CPU, RAM, red y carga del sistema, correlacionando métricas del SO con indicadores internos del app.

🧠 Gestión de Memoria

El Heap Memory aumentó progresivamente con la carga de bloques. El Garbage Collector de JavaScript liberó recursos al eliminar objetos, aunque con ligera latencia.

🧪 JMeter — Pruebas de Carga

El sistema mantuvo 0% de errores y 1 ms de tiempo de respuesta con hasta 60 usuarios concurrentes sobre localhost, evidenciando buena capacidad de respuesta.
